# HUESO — EL VOLCADO ES EL REPO

Un repo de 202 archivos y 95.781.877 B donde el 98,5 % es un solo
directorio de volcados de conversaciones. El proyecto no contiene el
volcado: el volcado contiene al proyecto.

## Lo que el volcado dice de sí mismo

Sus dos índices pequeños se contradicen en 47 mensajes (19.595 la
tabla LEEME, 19.642 el índice) y la contradicción se resuelve sin
residuo cuando se cuenta lo que cada uno esconde: un archivo duplicado
(`chat.json` es `conversations (4).json` con otro nombre, 1.007
mensajes contados dos veces) y un archivo reparado (`parte1grande`,
976 mensajes que el índice marca con 0). El resto son diferencias de
1–5 mensajes en cinco archivos, sin causa escrita.

El catálogo dice 38.331 expansiones y el índice las lista como 38.331
filas con 0 mensajes. Una expansión no es un mensaje: es un registro
de haber aprendido algo. El 99,95 % de lo aprendido fue "aprender del
historial de conversaciones" (38.313 de 38.331). El sistema se miró a
sí mismo 38.313 veces y descubrió 18 recursos nuevos.

## Principio

Un almacén de memoria que no cuadra consigo mismo no está roto: está
documentando su propia absorción. Dos índices, dos totales, y la
diferencia exacta entre ambos es la historia de cómo se hizo la copia:
un duplicado, una reparación, cinco redondeos. La memoria no miente
cuando discrepa: deja la costura a la vista.
